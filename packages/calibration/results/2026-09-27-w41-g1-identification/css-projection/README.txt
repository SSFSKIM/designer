Two measured routes, neither adopted
-----------------------------------
For each public uniform group's encoded RGB, L=.2126R+.7152G+.0722B;
F uses the frozen neutral piecewise-linear curve with end-segment continuation
and output clamp; g interpolates the frozen three ordinates with endpoint hold.

1. saturate(s), then minimum-alpha NEUTRAL plate rgba(n,n,n,alpha).
   n=255 if F>L, n=0 if F<L, alpha0 if equal. Normalize L,F to [0,1]:
   alpha=(F-L)/(1-L) on white, (L-F)/L on black; s=g/(1-alpha).
   The manifest records n, alpha, s (named saturation), side, and intermediate
   clipping. There are 128 white and two black cells; the latter are grey255.
   Four cells have algebraic intermediate saturation clipping. CSS saturate's
   nominal weights (.213,.715,.072) differ from E3's (.2126,.7152,.0722);
   neither this discrepancy nor intermediate clipping is erased from prediction.
2. contrast(c) THEN brightness(b), k=F-gL, b=g+2k, c=g/b.
   Domain g>=0,k>=0,b>0; all130 cells meet it. k ranges
   0.002687962959110446 to 0.4424775169622096, b ranges
   0.9436861804279162 to 1.8141608632903332. Since 0<=c<=1,
   the intermediate contrast result stays in [0,1], so its clamp is inert;
   brightness's final clamp equals clip(g*x+k). This is pure algebra, not a
   claim about Chromium's actual output.

What this prototype deliberately does NOT carry
----------------------------------------------
The current CSS host uses inherited border-radius; these fixtures use that same
circular CSS geometry (capsule min dimension/2, rrect declared radius), NOT a
supplied-native-path clip that would silently improve the production silhouette.
The production host also has a transparent layout border, isolation:isolate and
negative-z children inset by minus the border width; the standalone fixture has
no content or layout border and places its one body filter over the declared
outer box directly. It does not claim to reproduce that DOM stacking contract.
The inherited reader still uses the supplied paths to define deep measurement
masks. Geometry mismatch is outside this BODY reach reading; edge bins are only
web diagnostic output, not native boundary fidelity or production veto results.

css-tier.ts's L1 is sharp blur+saturation, L2 re-blurs L1 with a spatial share,
and L3 paints above both. Its encoded form retains the whole RGBA layer; its
linear form retains a FLOOR-alpha RGBA layer unconditionally. A real tint and
border must survive a silent backdrop-filter no-op. Removing that floor to make
contrast/brightness match would violate fallback legibility. Moving a colour
transform into L1 before L2 creates a boundary residual. No such integration is
implemented or approved here. The fixtures omit both blur layers, mask, floor,
border, rim and shadow because they isolate uniform deep body reach only.

optics.ts BODY_CHROMA_RETENTION=0 is an existing measured decline, NOT permission
to change saturation. tier-coherence.test.ts pins it against shipped endpoint
retentions and the authored regular1.8/clear1.4 saturation mapping. Both files
