The algebra (L = literal; R = a reading this memo tests; t = clamp((s-64)/96, 0, 1); d = SDF depth in pt).
The table gives each term with what it rests on.
| term | algebra | basis |
| capture | S = F * B restricted to R_fp | L: R_fp = box + margin; R: F is the 0.8-dev floor at f = 2 dev per texel (1.6 dev on rrect-lg) |
| narrow | C = G(kappa·5·o(d)) * S | R, 'var'; ruling 9's 'mix' reads (1-o)·S + o·G(kappa·5) * S |
| fill | W = G(kappa·8) * S | L on R_fp |
| light | N = C + 0.9·max(0, W - C) | L |
| dark | N = C - 0.9·max(0, C - W) | L |
| normal | M = 0.5·N + 0.5·W | L |
| output | y = T(M), or face(M) | R |
- o(d): active interp(d, [-s/2, -1], [0.8t, 0.4t]); receded 0.4 + 0.4t (L).
- Lighten-then-normal and normal-then-lighten are the same algebra when both use one W. The order question is
  therefore where T or face sits (R1), or where the narrow blur sits (R2), not the order of the two fills.
