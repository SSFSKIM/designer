4. WHAT THIS IS, AND WHOSE IT IS
----------------------------------
One mechanism under all of it, and it is already named: the CSS tier resolves the response law from
one backdrop level for the whole surface, which is right over a solid (`dark-solid__rrect-md`
0.0307 -> 0.0046) and much too dark over a structured backdrop. W21 Decision Log 3 (a) recorded that
as the CSS-only residual of wave Decision Log 23 (a) and deferred the bounded diagnosis by name,
because a CSS derivation change moves the light captures this wave binds byte-identical (X3).

What the ruling did not weigh is that the gate has adopted cross-tier coherence bounds, and a
residual recorded on one axis is an exceedance on another. That is the W16 lesson in a new place:
the dry run's referee measured the material and did not run this file over the candidate matrix, so
the landing is where it was read. The three constructs a ruling can reach are the bounds, a
regression floor pinned at the measurement with a §5.27 row saying what stopped being claimed, and
the CSS derivation itself — the first is a widening the doctrine forbids, the second is a user
decision, and the third is a wave. None of them is the landing worker's, so none was taken.

The GPU tier, which is this wave's chartered target, misses nothing: every dark texture row is
inside its adopted bound at both scales except the 2x nested pane's IoU above, and the tier's
calibration ΔE mean fell 0.0085 -> 0.0041 with the holdout 0.0300 -> 0.0161.
