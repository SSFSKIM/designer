System Settings > Accessibility > Display (1.22 h at the bar):

  DRY=1 $R/run-sitting-27.sh inactive 1 increased-contrast   # 22

No VITREA_SITTING_DIR and no VITREA_BED_FILE: the accessibility mode is part of the pass's
identity, so each pass has its own run directory ($HOME/vitrea-w29-27-run/<mode>-<pose>-<scale>x/
run-N) and its cell list is derived per pass from the declaration. The four standard rehearsal
lines were run on 2026-09-18 and are in logs/rehearsal.txt; the four accessibility ones need the
toggle first, which is why they are not.
