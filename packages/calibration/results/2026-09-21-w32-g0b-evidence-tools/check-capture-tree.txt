a string compare to disagree on. A document-hash checker cannot see it, and saying so is
better than a checker that appears to cover it.

So this run closes the generation half of the tracker entry and leaves the other half open
and named: the only instrument that sees a re-capture at unmoved bytes is a
`compare --skip-capture` re-derivation of the metrics off the tree's own PNGs, which is how
W31 G0 found those two cells in the first place. That is minutes of CPU rather than a file
walk, it is a different tool, and it is now the narrowed tracker entry.
