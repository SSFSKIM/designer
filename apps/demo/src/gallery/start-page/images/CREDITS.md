# Image credits

The four photographs Daybreak paints as its environment, one per phase of the day. Each file was
downloaded from Wikimedia Commons, resized where it was wider than 2560 px and re-encoded as WebP;
at display the page crops each one to the window (cover-fit, per-photograph focal point) and, in
the dark colour scheme, darkens it with a tone curve (the "evening print", `DESIGN.md`). No other
change is made to any image.
