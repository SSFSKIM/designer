## Scientific design under completion

The authorised form is a correction of the deep/low-pass component with the high-pass gain held.
The source correction matters: W50 already changes a group/surface-mean neutral term, not a
pointwise tone-map input. For an untinted sampled body before appearance, the linear form is
`C = G B + Q`, with `G = (1-k)(1-a) + k t`: `B` is the existing sampled backdrop, `k` collapse,
`a` solved alpha and `t` collapse transmission. If W50 only moves the neutral part of `Q`,
then `G` is already held. A later spatial inner-shadow multiplier and level-dependent rim can
still change full-silhouette variance. G0 must quantify that explanation on the exposed W51
impulse cells before deciding which component and placement actually separate level from detail.
A zero gate must retain the old executed path exactly; a new leaf is not required merely because
this is a new wave, and reuse of the existing inert chart is evaluated first. Mathematical
invariance at a fixed low-pass input is not a claim that every full-silhouette texture statistic
is invariant: the declared impulse referees and complete strata decide that empirically.

The fit population is W50's 840 cells / 1,856 statistic keys; capsule/sm/ml/lg canonical impulse
rest cells at both positions and scales are 16 named fit-time referees, not held out. Four
capsule identities already belong to fit840; the other twelve add 22 statistic keys, making
the fit-time union 852 cells / 1,878 keys. All sixteen are non-blind at the gate. The identical
real-pipeline rehearsal stays fit840 / 1,856 keys, not that larger union. The fresh gate retains the 1,341
physical identities, and the unspent exposure retains 322. Exact key lists, overlap, source
