## Scientific design — W52-DL3

### The corrected mechanism and operator

W50 changes the group/surface-mean neutral term, not a pointwise tone-map input. For an untinted
sampled body before appearance, `C = G B + Q`, with `G = (1-k)(1-a) + k t`: `B` is the sampled
backdrop, `k` collapse, `a` solved alpha and `t` collapse transmission. The W50 chart moves Q;
later inner shadow multiplies that change spatially and the level-dependent rim reads it.
Offline source prediction accounts for 87–113% of the observed standard-deviation reduction
on the twelve losing impulse-rest cells; the rim is the main coupling. Reproducible numerical
artifacts and their independent review are required before this declaration is sealed.

Reuse `lowEndStrength`, `lowEnd44`, `lowEnd96`, and `lowEnd160`; no new material leaf, uniform
lane, blur or sampling statistic is introduced. Their W52 meaning replaces their unshipped W50
meaning. **W50's fitted values are not meaningful as W52 coefficients.** Historical W50/W51
source revisions and evidence remain authoritative for those old readings, not current source.
All shipped endpoints keep strength zero; the existing identity-table group remains the gate.
Its historical identity values/pins are preserved, with prospective semantic documentation/tests.

The chart retains encoded input knots 0/8/28/40 and physical span rows 44/96/160, held beyond the
outer spans, and its fixed join at input64 to the old response at the actual span. This is a
request for a DC level (the spatially constant component supplied by the existing measured mean),
not a new spatial blur. Preserve the old W9 response solve, authority, clamped neutral and solved
alpha with the low-end chart excluded from that OLD path. Compute the actual old composite DC
from those solved values, its collapse/transmission and the independent linear mean—not merely
from the old response target, which partial authority or clipping may not achieve.

`delta = lowEndStrength * (decode(chartTarget) - actualOldDC)`

Carry this signed linear-light difference around the old body/appearance calculation and add it
after inner shadow and rim, before output encoding/coverage. Neither the old alpha, scatter,
collapse, chroma, inner-shadow field nor the rim's material-level input receives the correction.
Retain the established no-tone, policy, near-zero-alpha and fully-collapsed stand-downs; presence
multiplies the difference once. At strength zero or input at/above64 take the exact old path.
For a fixed mean/span on an untinted full-coverage sampled surface, the correction is a constant:
`C_new = C_old + delta`, so every pairwise linear difference and the old residual gain is held.
This is not a theorem about the encoded eight-bit image, changing coverage, gamut clipping,
spatially varying merged-group inputs, or a threshold-selected native mask. The named referees
and all full-union strata, not that algebra alone, determine captured T1.

### Paint, unsampled WebGPU and CSS

For an author tint, preserve the old material/shade/rim inputs. Transport the DC difference
through the existing encoded paint blend with its OLD shade held: compute that blend on the old
untinted color and on old color plus the presence-folded delta, and carry only their linear RGB
difference to the late addition. This is a bounded color residual calculation, not a duplicate
optics path. Full paint coverage suppresses the difference exactly; tint zero is the scalar DC
addition. The strict invariant is untinted only: the encoded paint blend and gamut can change
local gain under partial paint, and this is an explicit gated/visual residual, not an exact
high-pass claim. The fixed paint shade deliberately does not feed corrected level back into a
second level-dependent appearance law.

The late correction stands down on unsampled WebGPU paths (including the DOM proxy material
path); a straight translucent layer color does not represent a full-composite linear delta.
Those paths retain their old solve and appearance even when the selected document names an
active chart. Record this sampling-path residual and preserve backend honesty; do not invent an
alpha change to hide it. Sampled image/canvas/video WebGPU is the fitted fidelity target.

CSS explicitly declines the new placement. Its runtime material projection retains the old
response, not the W50 chart under W52 coefficient names. A prospective approximation would alter
an rgba-layer or linearRGB-filter intercept from the same scalar delta with its slope held;
it is not the declared late GPU correction because encoded layer mixing and separate
shadow/contour layers still spatially modulate it, and the encoded overlay cannot carry an
independent signed linear offset. No opacity workaround is admitted. The unchanged CSS level
gap is a measured tier residual, to be enumerated from the retained current evidence. CSS
level-error growth and its existing coherence contract remain gated; macOS27 coherence retains
its source-owned presence/reporting scope, not an invented new numeric bound.
